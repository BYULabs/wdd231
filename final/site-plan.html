AniStream Site Plan

WDD 231: Web Frontend Development

Site Name

Name: AniStream

Reasoning: The name merges "Anime" and "Streaming/Discovery". It directly communicates the core identity of the platform as a fast, liquid hub for modern, high-speed discovery and browsing of real-time seasonal dynamic anime catalogues.

Optional Domain Availability: anistream-discover.org

Site Purpose

AniStream acts as a lightweight, modern client-side discovery pipeline for tracking current ongoing anime broadcasting seasons. The purpose is to allow enthusiastic viewers to filter ongoing trends, read localized description snippets, check score rankings immediately, and configure layout queries clean of structural platform overhead.

Target Audience Scenarios

The following persona tracking scenario layouts drove the design requirements for the platform's user interface:

  • Scenario 1: "What are the most popular, top-voted anime series currently broadcasting live right now this season?"
  • Scenario 2: "Where can I quickly check the specific animation studios behind a dynamic card show without clicking through multi-layered profile pages?"

Color Scheme

The platform relies heavily on dark, high-contrast values to allow colorful anime key art grids to visually pop off the viewport canvas layer, satisfying ideal contrast criteria.
